# Schibsted Account SDK for browsers documentation

This repository is used only to host versioned public documentation for the
[`@schibsted/account-sdk-browser`](https://www.npmjs.com/package/@schibsted/account-sdk-browser)
package.

[View the public SDK documentation](https://schibsted.github.io/account-sdk-browser/).

## Documentation structure

Versioned documentation is stored in `docs/<version>/`. The `docs/versions.json` file lists the
available versions, and `docs/index.html` opens the latest published version. GitHub Pages publishes
the contents of the `docs/` folder.

The SDK source code is maintained internally in a private Schibsted repository. This repository is
no longer used for source development.
